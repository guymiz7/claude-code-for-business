חברת בנייה — המסע מ-No-Code ל-Claude Code

לרעם, בעל חברת בנייה, התחלנו את המסע כמו לכל לקוח אחר — עם הסטאק המקובל בשוק:
Airtable + Fillout + אינטגרציות ב-Make.

ניסינו להמיר ל-Fireberry · עלות: ~1,000 ש"ח לחודש

שלב 3 · המעבר ל-Yes-Code
Claude Code + Supabase + Vercel · עלות שוטפת: ~60 ש"ח לחודש (שרת בלבד)
50 שעות עבודה - והגענו לתוצאה המדויקת

חברת כשרויות בארה"ב — צרכים שאין למערכת מדף

התהליכים העסקיים של משה שונים מכל מה שראינו אצל לקוחות אחרים — וזו בדיוק הסיבה שמערכות מדף לא מתאימות לו.

המודל העסקי
חידוש שנתי מחזורי + תוספות במהלך השנה עם נוסחאות מורכבות שמותאמות רק אליו
האתגר הויזואלי
כל סוג תוספת דורש ממשק שונה והתייחסות נפרדת - דבר שמערכות סטנדרטיות פשוט לא תומכות בו
הפתרון הדו-לשוני
החברה עובדת בעברית וגם באנגלית במקביל - מה שנכתב באנגלית מתורגם אוטומטית לעברית בצד השני. שתי השפות חיות יחד באותה המערכת.

הלקח: ייחודיות עסקית = הזדמנות. במקום להכריח את העסק להתאים את עצמו למערכת, אנחנו בונים מערכת שמתאימה אליו.
